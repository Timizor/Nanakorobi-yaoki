\# Comenzi Git



\## Verificare

\- `git status` - verifică starea fișierelor

\- `git log --oneline` - afișează istoricul commit-urilor

\- `git remote -v` - afișează repository-urile remote



\## Modificări

\- `git add .` - pregătește modificările

\- `git commit -m "mesaj"` - creează un commit

\- `git push` - trimite commit-urile pe GitHub

\- `git pull` - preia și integrează modificările remote



\## De exersat

\- \[ ] Adaugă un fișier nou

\- \[ ] Modifică un fișier existent

\- \[ ] Creează o ramură

\- \[ ] Fă merge între două ramuri
