\# Git Practice



\## Ce am învățat



\- `git stash` — salvează temporar modificările.

\- `git stash pop` — recuperează modificările salvate.

\- `git revert` — anulează un commit printr-un commit nou.

\- `git switch -c` — creează și schimbă branch-ul.



Exersez comenzile Git pentru a învăța să lucrez cu branch-uri și GitHub.
